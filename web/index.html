它是怎么工作的
网页界面和 MCP 服务共用同一个本地 SQLite 数据库。AI 通过 MCP 写入的笔记会立刻出现在左侧列表里 （带 AI 标记）， 你可以在网页里继续编辑，也可以让 AI 追加内容。所有笔记都是纯 Markdown 明文。
