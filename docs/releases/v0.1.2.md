# Locknote AI v0.1.2

本次更新重点优化 Windows 安装与启动流程，补充数据库维护和启动诊断，并改进 AI 助手的历史会话体验。

## 主要更新

- **Windows 安装完善**：统一主程序名为 locknote-ai.exe，修复 NSIS 安装后仍使用旧名称的问题；MSI 增加安装向导、安装目录选择与许可证，完善快捷方式目标和 WebView2 检测。
- **数据库启动优化**：正常打开不再全量检查 FTS，保留必要迁移与索引初始化；新增 check-db 和 repair-indexes，修复前自动生成包含已提交 WAL 数据的一致性备份，索引重建在事务内完成。
- **首屏按需加载**：历史对比与插件管理延迟至打开时加载，统计查询延后执行；当前笔记加载完成后才报告可交互，Mermaid 加载失败可重试。
- **启动诊断与发布检查**：新增本地 startup.log 和 Windows 安装、启动、MCP、升级、卸载验收脚本；发布流程增加实际载荷、快捷方式验证及失败日志保留。
- **AI 助手 0.4.5**：历史列表显示会话名称与时间，删除改用小图标；首次成功回复后延迟生成简短会话名并本地保存，仅发送有限的首轮对话片段。

## 升级提示

- 升级前退出应用并备份数据。默认目录仍为 ~/.locknote-mcp/，无需因程序改名移动资料。
- 数据库备份不包含插件文件、配置和 AI 聊天记录，请另行备份 plugins/；未应用建议稿位于本机 WebView 存储。
- AI 助手为独立插件，请在插件市场升级至 0.4.5，或导入相应 ZIP；安装新版应用不会自动升级插件。
- Windows EXE 和 MSI 均需预装 Microsoft Edge WebView2 Evergreen Runtime；离线环境请先安装 Evergreen Standalone Installer x64。
- Windows 安装包命名为 locknote-ai-0.1.2-windows-x64.exe / .msi，安装后的主程序为 locknote-ai.exe。

## 验证状态

本地 Go 测试、go vet、前端构建与测试，以及 Windows x64 GUI 主程序交叉编译已通过。MSI/NSIS 安装、升级、卸载和 Windows 11 实机性能仍待验证；本次不宣称已解决所有 Windows 11 安装问题或达到特定启动秒数。详见 [Windows 验收报告](../windows-acceptance-report.md)。
