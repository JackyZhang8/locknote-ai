# Locknote AI v0.1.1

本次更新带来桌面插件系统、AI 助手，以及更完整的笔记历史对比与改动审阅体验。

## 主要更新

- **插件系统**：在「设置 → 插件」拖入 ZIP 安装，支持启用、禁用、配置、卸载与升级确认；可扩展侧栏、工作区标签页、底部面板、菜单和命令，支持中英文切换。
- **AI 助手插件**：右侧聊天，支持配置 OpenAI 兼容 Provider、测试连接和获取模型列表，默认模型为 `deepseek-flash`。可结合当前笔记多轮对话，按需搜索和读取其他笔记；聊天记录本地持久化，重启后恢复最近会话。
- **可审阅的笔记改动**：AI 建议先展示差异，支持编辑、应用、丢弃或保留稍后处理。应用与撤回校验版本，保护后续编辑，避免把未应用建议误报为已保存。
- **历史版本对比增强**：更大的对比窗口，支持任意版本比较、并排／合并模式、增删配色、同步滚动、差异定位和长文虚拟渲染；恢复前确认并检查版本。
- **开发示例与 SDK**：提供 AI 助手、大纲、笔记检查三个示例及打包工具，完善 TypeScript 类型、配置冲突处理、生命周期与事件接口。

## 修复与改进

- 修复重启后插件入口未恢复、菜单重复、顶部与侧栏按钮开关不同步。
- 优化 AI 助手长回复、历史／配置遮层、审阅按钮及未应用改动保留逻辑。
- 修复插件改动的分类与置顶恢复，保存后的刷新失败不再误报写入失败。
- 修复 Linux AppImage 打包工具下载 404，完善跨平台安装包和中英文文档。

## 升级提示

升级前请退出应用并备份数据。默认数据目录仍为 `~/.locknote-mcp/`。示例插件需按仓库文档打包后安装或升级，不会随应用自动安装。

数据库备份不包含插件配置和 AI 聊天记录，请另行备份数据目录中的 `plugins/`；未应用建议稿保存在本机 WebView 存储中。仅安装可信插件。AI 助手会将相关内容发送至配置的 Provider，API Key 与会话在本机明文保存。
