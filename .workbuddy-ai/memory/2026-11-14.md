# 2026-11-14

## 应用图标改版（光感 + 轻微玻璃感）

- 目标：在保留「书本 + 锁」造型和米色/墨绿品牌色前提下，给图标加入光照层次与玻璃质感。
- 做法：以 `web/icon.svg` 的原始矢量路径为基础重写 SVG（渐变、径向光晕、内缘受光描边、玻璃斜扫、轻落影），
  用 headless Chrome 以 2x 渲染后 LANCZOS 降采样到 1024，写入 `build/appicon.png`；`web/icon.svg` 同步更新。
- 关键坑：
  - SVG `<mask>` 按亮度计算，遮罩内所有形状必须显式 `fill="#FFFFFF"`（含圆形、书页 path），否则默认黑色 = 透明。
  - 「轮廓上移副本」做边缘高光会把内部整体提亮（大块填充偏移 6px 仍覆盖 99% 面积），
    正确做法是用同形状 + 渐变描边（`stroke-width≈9`），再由遮罩裁掉外侧一半，得到真正的内缘亮边。
- 渲染命令：`"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless=new --disable-gpu
  --user-data-dir=/tmp/iconv2/profile --force-device-scale-factor=2 --window-size=1024,1024
  --default-background-color=00000000 --screenshot=out.png file:///path/icon.svg`
- 环境注意：本机 shell 的 PATH 不含 /usr/bin、/usr/local/go/bin，go 需用绝对路径，且需 `CGO_ENABLED=1`
  才能编译 `appicon_darwin.go`（否则报 `undefined: setApplicationIcon`）。
- 图标源文件即 `web/icon.svg`（同时用于应用内 logo 与 favicon），改图标只改这一个文件再重新导出 PNG。
