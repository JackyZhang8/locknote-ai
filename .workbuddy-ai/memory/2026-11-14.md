## 应用图标改版（光感 + 轻微玻璃感）

- 目标：在保留「书本 + 锁」造型和米色/墨绿品牌色前提下，给图标加入光照层次与玻璃质感。
- 做法：以 `web/icon.svg` 的原始矢量路径为基础重写 SVG（渐变、径向光晕、内缘受光描边、玻璃斜扫、轻落影），
  用 headless Chrome 以 2x 渲染后 LANCZOS 降采样到 1024，写入 `build/appicon.png`；`web/icon.svg` 同步更新。
- 关键坑：
  - SVG `<mask>` 按亮度计算，遮罩内所有形状必须显式 `fill="#FFFFFF"`（含圆形、书页 path），否则默认黑色 = 透明。
  - 「轮廓上移副本」做边缘高光会把内部整体提亮（大块填充偏移 6px 仍覆盖 99% 面积），
    正确做法是用同形状 + 渐变描边（`stroke-width≈9`），再由遮罩裁掉外侧一半，得到真正的内缘亮边。
- 渲染命令：`"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless=new --disable-gpu
  --user-data-dir=/tmp/iconv2/profile --force-device-scale-factor=2 --window-size=1024,1024
  --default-background-color=00000000 --screenshot=out.png file:///path/icon.svg`
- 环境注意：本机 shell 的 PATH 不含 /usr/bin、/usr/local/go/bin，go 需用绝对路径，且需 `CGO_ENABLED=1`
  才能编译 `appicon_darwin.go`（否则报 `undefined: setApplicationIcon`）。
- 图标源文件即 `web/icon.svg`（同时用于应用内 logo 与 favicon），改图标只改这一个文件再重新导出 PNG。
- 用户已确认 locknote-mcp 的图标定稿，**不再修改**。

## locknote-client 图标（最终：书页上的盾形锁印花）

- 造型沿用 server 版书本轮廓，配色换成 client 品牌：底板薄荷 `#BAEFD4` 系、书本 `#1BCC71` 系。
- **用户逐步明确的要求（务必按这个来）**：
  1. 锁不是放在 icon 中间，而是**左右两个封面各一个**；
  2. 锁要**简洁**，照参考 favicon 的极简实心挂锁（无钥匙孔、无内部细节）；
  3. **锁的周围要有盾牌**（参考 favicon 里锁被浅薄荷盾牌包着）；
  4. **盾牌 + 锁整体印在书页上**，且**跟书页同一个倾斜角度**（左页 +16°、右页 -16°）；
  5. 是「印」：平涂、无阴影、无浮雕、不做挖空，锁是实心品牌绿。
- 盾牌轮廓不是手画的五边形：从参考 PNG 逐行提取薄荷色像素的左右边界，归一化到
  `宽100 × 高111`（原点在顶部尖），用 Catmull-Rom 转三次贝塞尔拟合。
  **端点要用「镜像虚拟点」**，否则顶部/底部会变成尖刺。
- 倾斜用 `skewY(±16)`（透视贴合，图案随载体形变）而不是 `rotate`；用户看过 rotate 版后要求重画。
  变换链：`translate(332|692,650) skewY(±16) scale(2.05) translate(0,-55.5)`。
- 两个方案的源文件都在 `/tmp/clienticon/`：`redrawD.svg`（交付，透视倾斜）、`redrawF.svg`（整体旋转备选）。
- 输出到 `locknote-client/icons/`：16/32/180/192/512/2048 PNG、多尺寸 ico、矢量 favicon.svg；
  原图标已备份到 `icons/_backup_original_2026-11-14/`。`build.sh` 会同步 2048 版到 `build/appicon.png`，已手动同步一次。
- favicon.svg 用 `<use href="#printArt">` 复用印花单元（无 mask，Safari 兼容）。
- **Chrome 渲染尺寸坑**：`--window-size` 是 CSS 像素，SVG 固定 1024 时窗口开 2048 会让图形只占画布左上 1/4；
  正确做法是 `--window-size=1024,1024 --force-device-scale-factor=2` 得到填满的 2048 图。
- 该机 Chrome 需加 `--no-sandbox` 才能在工具沙箱内跑（否则 `aperitif: Failed to initialize sandbox` 直接退出）。
- 24 位 PNG 体积：2048 约 2.2MB、512 约 150KB（渐变+模糊层导致），量化到 256 色会出现明显色斑，不要量化。
